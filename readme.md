## 1. Project Overview

The Smart Campus Services System is a Python-based Object-Oriented Programming application designed for Uganda Christian University. It manages student digital accounts, processes campus service transactions (such as cafeteria purchases and printing services), enforces strict encapsulation controls, handles operational errors gracefully, and persists transaction logs to local file storage.
